# Project Icons

Minimalist vector icons for each project card, referenced by the `icon` field in
`app/components/projects.tsx` (e.g. `icon: "/projects/icons/clauto.svg"`).

| Project                  | File                             | Style / Source                                        |
| ------------------------ | -------------------------------- | ----------------------------------------------------- |
| Clauto                   | `icons/clauto.svg`               | Terminal prompt `>_` with autonomous orbit indicator  |
| Trillium Pastry          | `icons/trillium-pastry.svg`      | Official Trillium Pastry floral/pastry SVG emblem     |
| ZUIX INC.                | `icons/zuix.svg`                 | Official architectural roofline & monogram logo       |
| Anti-FOMO                | `icons/anti-fomo.svg`            | Radar dish with concentric telemetry signal waves     |
| GradeMatrix              | `icons/grade-matrix.svg`         | Academic graduation mortarboard & GPA analytics       |
| Pico-Ducky 3.0           | `icons/pico-ducky.svg`           | Cybernetic rubber ducky silhouette with HID accent    |
| Fretnote                 | `icons/fretnote.svg`             | Guitar plectrum with fretboard & harmonic fret markers|
| opencode for Journalling | `icons/opencode-journal.svg`     | Open notebook with AI intelligence knowledge sparkle  |
| Undercut                 | `icons/undercut.svg`             | Aerodynamic sports coupe silhouette with headlight cut|
| FocusBox                 | `icons/focusbox.svg`             | Isometric lockbox cube with ambient timer ring        |

Cards display a 48×48 px icon container with a subtle brand-gradient accent border.
Leaving `icon` empty renders a clean gradient initial avatar fallback.
